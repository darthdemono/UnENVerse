Comparison

UnENVerse is for people who run their own software: developers, homelab owners and small teams. This page compares kinds of tool, not named products, and only on things this project can verify about itself.

What UnENVerse is not

  • Not a hosted service: nobody runs it for you, and there is no account to recover a lost master password with.
  • Not a replacement for a team-scale identity platform. Permissions exist, but a single maintainer wrote them and no outside audit has certified them. See the security page for what has and has not been reviewed.
  • Not on macOS releases yet. See Install.
