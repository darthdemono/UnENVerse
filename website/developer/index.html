Developer

UnENVerse is a Tauri 2 desktop app (TypeScript and Vite in src/, Rust in src-tauri/), the unv CLI, an optional unv-server, and vault-core, the library that holds storage, crypto, permissions and nodes.

Read first

  • Architecture: how the pieces fit and why.
  • API reference: the server's routes, generated from the code.
  • The scripting contract: exit codes and JSON envelopes unv promises to scripts. unv describe prints it as JSON.
  • Decision records: the reasons behind choices.
  • Roadmap and the changelog.

Build and test

npm ci
npm run dev            # Vite only, for UI work
cargo tauri dev        # the full desktop window
npm run check          # format, lint, typecheck and the TypeScript tests
cargo test --workspace # all Rust tests
npm run preflight      # what CI runs

Ground rules

  • Whatever the UI can do, the CLI can do, and the reverse; exemptions are written down.
  • Vault data is untrusted input and is escaped on every render. Redaction fails closed.
  • A bug fix comes with a regression test that fails without it.
  • CONTRIBUTING.md has the full list, and the repository has the code.
