Get help

Most questions are answered on a page you can read in a minute. Try these in order.

  1. The FAQ for the common questions.
  2. The quickstart and the guides for a task from start to finish.
  3. unv doctor. It checks the database, the salt, file permissions, the audit chain and common setup mistakes, and says what to fix.
  4. unv <command> --help, and the command reference.
  5. The changelog, in case the behaviour changed in a recent version.

Asking on GitHub

Open an issue and include:

  • The version (unv --version, or the About box in the app), and your operating system.
  • What you ran and what you expected, with the exact error text.
  • The output of unv doctor, which contains no secret values.

Do not paste master passwords, tokens, vault files or --reveal output. If something already leaked, read if something leaks.

A forgotten master password cannot be recovered by anyone, including the maintainer. Backups and the recovery key are the only way back, and they are set up before you need them: see the command line guide.
