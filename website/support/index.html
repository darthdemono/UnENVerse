Support the project

UnENVerse is free for noncommercial use and source-available, with no paid tier and nothing to buy. It is written and maintained by one person, so the useful kinds of support are the ones that save that person time.

  • Use it and say what broke. A bug report with the version, the steps and what you expected is worth more than a star. Open an issue on GitHub. Never paste a real secret into an issue.
  • Send a fix with a test. The rules are in CONTRIBUTING.md: a bug fix comes with a test that fails without it.
  • Report a vulnerability privately. Use the private form described in SECURITY.md, not a public issue.
  • Improve the docs. The guides and the book are in the same repository; a confusing step you found is a reason to change it.
  • Check an import. Importers for other password managers are written from published formats. A sample export (with the secrets replaced) from a tool you use is the fastest way to make an importer correct.
  • Star the repository and tell someone. It helps other self-hosters find it.

The project does not take donations at the moment, and this page will say so if that changes.
