Docker

The server is published as a multi-architecture image for linux/amd64 and linux/arm64 on the GitHub container registry. Mount a volume at /data so the vault survives the container. Set UNV_PASSWORD to unlock on start-up, or leave it unset and unlock with POST /api/unlock:

docker run -d --name unv-server -p 127.0.0.1:8743:8743 \
  -v unv-data:/data \
  -e UNV_PASSWORD=your-master-password \
  ghcr.io/darthdemono/unenverse/unv-server:{{VERSION}}

The port is published on this machine only: the server speaks plain HTTP unless it is started with --tls, and the master password travels in every sign-in. Add --tls after the image name, or put a TLS proxy in front, before publishing it to other machines.

Or with Compose:

services:
  unv-server:
    image: ghcr.io/darthdemono/unenverse/unv-server:{{VERSION}}
    ports: ["127.0.0.1:8743:8743"]
    volumes: ["unv-data:/data"]
    environment:
      UNV_PASSWORD: ${UNV_PASSWORD:-}
volumes:
  unv-data:

Tags: the exact version, the minor line (0.57) and latest. The image runs as an unprivileged user and starts unv-server with the vault in /data. Check the image with docker run --rm --entrypoint unv-server ghcr.io/darthdemono/unenverse/unv-server:{{VERSION}} --version.

All files, older versions and the release notes are on the GitHub release page.

Verify your download

1. Check the checksum. Download SHA256SUMS from the release into the same folder and run:

sha256sum -c --ignore-missing SHA256SUMS

On Windows (PowerShell):

Get-FileHash .\UnENVerse_{{VERSION}}_x64-setup.exe -Algorithm SHA256

On macOS, shasum -a 256 -c --ignore-missing SHA256SUMS does the same job. Compare the result with the matching line in SHA256SUMS.

2. Check the signature. Every asset has a keyless Sigstore signature (.sig) and certificate (.pem) made by this repository's release workflow. With cosign installed:

cosign verify-blob \
  --certificate <asset>.pem \
  --signature   <asset>.sig \
  --certificate-identity-regexp 'https://github.com/darthdemono/UnENVerse/.*' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  <asset>

A signature proves the file came from this repository's workflow. It is not an audit of the code.
