## 3. Pentest-style findings from this round (phase 39 follow-up)

1. **The listener served one connection at a time**: a client that connected and sent nothing held it for the I/O timeout, so one stalled socket every ten seconds kept the hub from ever polling. Fixed: a thread per connection, a hard 20 s total deadline, at most 16 at once, and only a whole, signed request takes the agent lock. Pinned by an e2e test with twenty stalled sockets.
2. **A `device` node was not held** (above).
3. Dynamic probe of a running `envv-server --nodes --tls`: unauthenticated beat, malformed headers, a 10 MB body (413), enrollment brute force (429 after ten), every owner route (401) and `PATCH /api/vault` unauthenticated (401) all behaved; the hub's own listener still accepts TLS 1.2 (the documented deviation of ADR-0140). Running the server with `--tls` and a temp `--db-path` still writes `server.crt`/`server.key` into `~/.local/share/envv-server` unless `XDG_DATA_HOME` is set; this run created two files there by mistake and removed them (they did not exist before: the directory held only the June `vault.db` and `vault.salt`).

## 6. Traps for the next agent

- `pkill -f "<pattern>"` kills the shell that contains the pattern (it did, twice). Use `pgrep` and `kill`.
- A backgrounded `( ... ) &` makes the task notification fire at once; poll the output file.
- `cargo fmt` between an edit script and a second `str.replace` silently breaks the replace; `assert old in s`.
- A line-number counter that rescans from the start per value is quadratic (the PHP parser took 104 s on 150,000 items); compute lazily.
- Prettier checks `vault-core/tests/fixtures/` unless ignored (it is now); fixtures are the assertion.
- A new Tauri command, CLI leaf or flag must be classified in `tests/fixtures/parity/capabilities.json` or `envv-cli/tests/capabilities.rs` fails.
- Fixed-size arrays of public fields (`PUBLIC_FIELDS_P23` in `out.rs`) need their length bumped when a field is added.
- Never edit `src/` or `tests/` while `npm run check` is running; the ADR/source citation tests read them as text.
