## The findings that mattered

planning session.

1. **Every 2FA code is blank on a remote vault** - verified in source, confirmed
   by the user's symptom. `entry_totp_code` refuses unless the _local_ SQLCipher
   key is held; on a remote session it is not, and `liveCodeFor` swallows the
   error. The user suspected a migration; it is not one. The whole Authenticator
   feature looks broken to anyone using `envv-server`.

   `downloadText` clicks a blob `<a download>` and toasts unconditionally; 15
   call sites; no dialog/fs plugin and no download handler in `src-tauri`.
   Reported only for ICS. **Unverified** - reproduce with two exports first.
3. **CI's lint exit code 2 is stale suppressions, not the 501 warnings.** The
   diagnosis the user pasted blamed the warnings and recommended `--suppress-all`,
   which `CLAUDE.md` forbids. `npx eslint --prune-suppressions` alone turns CI
   green. The full backlog is 501 warnings plus 236 suppressed errors.
4. **Inject can never work.** It requires the Add/Edit overlay open, and the Tools
   panel it lives in sits behind that overlay.
5. Seed-only entries already save (`primaryIsOptional`), so "standalone 2FA" meant
   a flow, not a validation fix.

### Findings from this pass

1. **A11 - older builds downgrade unknown types on Save.** `modals.ts:670` sets the
   type select to a value it has no option for (reads back `""`), and
   `modals.ts:252` falls back to `'api_key'`. Must ship in a release before 24.1.
2. **`filter_vault_for_user` rebuilds the vault from three known keys**, so any new
   top-level array (`bundles`) disappears for sub-users; the write merge preserves
   it. Recorded as B6/B7.
3. **Registry benchmark** (SQLCipher, rusqlite 0.31 - the pinned version - WAL,
   16-byte HMAC key, `WITHOUT ROWID`, date index; this 4-core desktop):

   | Rows                            | Bulk insert/s (1000/tx) | Single-commit insert/s | Lookup/s | Size    | Prune 10%                     |
   | ------------------------------- | ----------------------- | ---------------------- | -------- | ------- | ----------------------------- |
   | 1M (plain SQLite, for contrast) | 70,986                  | 33,660                 | 152,859  | 59.7 MB | 0.59 s                        |
   | 1M                              | 24,780                  | 12,095                 | 56,413   | 61.1 MB | 3.28 s                        |
   | 10M                             | 17,505                  | 10,663                 | 37,475   | 610 MB  | **45.7 s in one transaction** |

   HMAC-SHA256 ≈ 756k/s - never the bottleneck. **61 bytes per row, flat from 1M to
   10M.** The 45.7 s single-statement prune holds the writer lock the whole time,
   which is why prune is now chunked in the plan.

## Continued again - bundles as scopes (the Discord bot config)

The user asked for composites that reference bundle siblings and for a bundle to
be able to hold a whole config file, using an old Discord bot config (all values
revoked) as the example. It is a Python module, not a dotenv: f-strings, a hex
colour, snowflake ids, markdown links, and `api_key` assigned twice.

| Question                         | Answer                                                                         |
| -------------------------------- | ------------------------------------------------------------------------------ |
| Reference syntax inside a bundle | `{slot.field}` for a member, `{name}` for a local                              |
| Small non-secret values          | bundle-local variables                                                         |
| Derived values on export         | rendered by default, per format (f-strings in Python, template literals in JS) |
| Value kinds                      | all four groups: core + colour, templates, large ids + bitfields, dev formats  |

**Design change made because of it:** a bundle is now an **entry** of
`secretType: 'bundle'` whose `extra_vars` are its local variables, replacing the
top-level `VaultData.bundles` array written earlier the same day. It gets RBAC,
masking, history and env naming for free, older builds can read it, and Phase 25
has no bundle table to migrate. Recorded in `CLAUDE.md` as a same-day revision.

Findings from the example, each now an edge case with a rule: Discord snowflakes
exceed 2^53 and silently round as JS numbers (B15, `large_id`); the duplicate
`api_key` binds positionally in Python, so the importer suffixes and rewrites
later references rather than letting the last one win; a composite over siblings
must carry **taint** so a URL containing `api_key` stays masked while the invite
link does not (resolution rules, B8).
